# Context Curation Under Distribution Shift

Code and experimental results for:

"Context Curation Under Distribution Shift"

## Overview

This repository contains the code, configurations, experimental results,
statistical analyses, and figures used in the study.

## Repository Structure

- `src/` — implementation
- `configs/` — experimental configurations
- `results/` — raw experimental results
- `analysis/` — statistical analysis scripts
- `figures/` — generated figures
- `notebooks/` — exploratory/reproduction notebooks

## Datasets

The study uses five public datasets obtained through OpenML:

- Adult
- German Credit (`credit-g`)
- Bank Marketing
- Diabetes
- Electricity (`elec2`)

The datasets are not redistributed in this repository.
